Color of Now

What color is this moment? Geolocation, weather, and Claude converge to paint today — then remember it forever.

Type Web Application
Stack React, Vite, Claude API
Year 2026
Status In development
Concept

A daily color
archive

Every moment has a color. Not the color you see — the color you feel. Color of Now reads the time, your location, and the weather outside, then maps that convergence to a single muted hue from a 24-hour palette designed to feel more like memory than data.

Claude then receives the raw input — city, hour, color name, temperature, sky condition — and returns two sentences in Korean. Not a description. A feeling. Something you could have written yourself, but didn't have the words for yet.

Each day, one color. One sentence. Saved quietly to your device. Over time, a calendar of every moment you stopped to look.

Design System

24 hours,
24 colors

The palette maps each hour to a muted, desaturated hue — avoiding the obvious (golden hour is golden, midnight is black). Instead, the colors feel like emotional states: dusty plum at 3am, warm ochre at noon, slate violet at 7pm.

Typography uses Bebas Neue for the oversized headline (with text-stroke for the outlined editorial effect) and Cormorant Garamond italic 300 for the poetic descriptions — a combination that feels both bold and quiet.

Technical

Four APIs,
one feeling

No backend. No server. Everything runs in the browser — the only data that leaves the device is the Claude API call, which is direct from browser using Anthropic's supported browser access header.

LocationBrowser Geolocation → lat / lng
↓
Sunsunrise-sunset.org → actual sunrise / sunset times
↓
WeatherOpen-Meteo → temperature, cloud cover, WMO code
↓
ColorHour → 24h palette lookup → hex + name
↓
Claudeclaude-sonnet-4-6 → 2-sentence Korean description

Entries are stored in localStorage — no account, no cloud, no tracking. The calendar builds itself from whatever you've saved. Close the tab and reopen it tomorrow; everything is still there.

Interface

A constellation
clock

The landing screen shows only two things: the oversized outlined text "color / of NOW" — where NOW takes the current hour's palette color — and a constellation-style clock in the lower section.

The clock uses SVG: micro-stars scattered inside the face, two dashed inner orbit rings, a four-pointed star for the hour hand with a radial glow, a smaller star for the minute hand, and a thin line for seconds. Around the outer ring, curved text reads: CLICK THE CLOCK · CLICK THE CLOCK ·

Clicking the clock triggers the full pipeline. The background transitions over 1.8 seconds to the hour's color. Claude's two sentences appear character by character. You can edit the text before saving. The calendar section below shows every day you've stopped to look.

Creating at the intersection of technology, emotion, and visual experience.
